# Plugin Store promo images

Marketing images for the Shipper listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-shipper](https://justinholt.com/plugins/craft-shipper).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `shipper-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp). **Promos are JPEG, never PNG**: Chrome can only write PNG, so
`build.sh` converts with `sips` at quality 90 and deletes the intermediate.

## Slides

| # | Slide | Shows | Strings come from |
|---|-------|-------|-------------------|
| 1 | Cover: name, tagline, app icon, price | — | `README.md` intro |
| 2 | Paste one URL into ShipStation | the settings screen's Connection section | `src/templates/settings.twig` ("Connection", "URL to Custom XML Page", the Username / Password / Auth key labels, "Generate a key"); URL shape from `Settings::getEndpointUrl()` |
| 3 | Every request, on a screen (Pro) | the connection log index, plus one entry's Request | `src/templates/log/_index.twig` and `_detail.twig` (columns When / Action / Status / Time / Summary, "All actions", "All levels", "{total} entries", "Prune old entries"); summaries from `ApiController` and `services/Api.php`; the masked `auth_key=***` from `ApiController::loggedUrl()` |
| 4 | Two parcels, one order (Pro) | the order screen's ShipStation panel and the order history | `src/templates/_order-panel.twig` (Carrier / Tracking / Shipped, "Sent to ShipStation {count} times…", "Preview XML", "Sync now"); history notes from `Shipments::buildNote()` |
| 5 | Retries that don't double up | two shipnotify requests an hour apart, one key | `Shipments::buildShipmentKey()` (`trackingNumber\|lower(carrier)`); summaries "Recorded shipment for order…" / "Duplicate shipment for order {number} ignored" |
| 6 | Live rates that fail open (Pro) | a checkout with ShipStation up, and down | rate descriptions "{name} — about {days} business days" from `LiveRateShippingRule`; fail-open behaviour from the "Enable live rates" instructions |
| 7 | "Where is my order?" | the Twig API and what it renders | the `README.md` Twig sample and `src/twig/ShipperVariable.php` |
| 8 | Two editions | Lite and Pro, with prices | the `README.md` editions table |

The mocks have to agree with the plugin. Order 1042 is the same order throughout: two notebooks went
by UPS (`1Z999AA10123456784`, slides 3–5 and 7), the pen followed by USPS, so it is "2 of 3 items
shipped" until the second parcel. A log *Action* cell shows the raw handle (`export`, `shipnotify`,
`rates`, `refresh`), because that is what `log/_index.twig` prints. A 401's summary is
"Invalid ShipStation credentials." and is written at most once a minute. Change a label, a summary or
the editions table and change the slide.

Order statuses ("Partly shipped", "Shipped") are the merchant's own Commerce statuses, chosen in
**Partly shipped status** and **Shipped order status**; the slide uses plausible names, not
plugin strings.

## Palette

Accent `#8B5E34`, the kraft-cardboard brown of the icon tile. `#E0B07A` is the light accent for small
things on the dark background (ticks, rules, inline code, the Pro column): the tile brown is too dark
to read there. Gradient headline text starts at `#C48A52` for the same reason. Plus the family's
`#ffd166` gold. Jersey 20 for display, Inter for body.

## The watermark is the glyph alone

`assets/watermark.svg` is the path from `../src/icon-mask.svg` (parcel, punched-out label, outbound
arrow) filled white, with no tile. The app icon is never used as a watermark. It is anchored
bottom-right, runs off the edge, and is switched off on the cover, where it would sit behind the icon
like a shadow.

`assets/icon.svg` is a straight copy of `../src/icon.svg`. Re-copy it (`cp`) whenever the icon
changes.

`fonts.css` is generated by `build.sh` and gitignored; don't edit it.
