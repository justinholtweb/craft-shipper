Front end

“Where is
my order?”

A tracking page in a few lines of Twig. Links built for 20+ carriers.

  • Also latestShipment, isShipped and knownCarriers
  • The raw payload, with its address, never reaches a template
templates/account/order.twig
{% for shipment in craft.shipper.shipments(order) %}
    {{ shipment.getLabel() }}
    {% set url = craft.shipper.trackingUrl(
        shipment.carrier, shipment.trackingNumber) %}
    {% if url %}
        <a href="{{ url }}">{{ shipment.trackingNumber }}</a>
    {% endif %}
{% endfor %}

{% set progress = craft.shipper.progress(order) %}
{{ progress.shipped }} of {{ progress.total }} items shipped
